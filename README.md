
# eDucate – Platform Pembelajaran Interaktif

![eDucate Logo](https://e-ducate-by-paprika-studio.vercel.app/logo.png)

eDucate adalah platform pembelajaran interaktif yang dirancang untuk membantu pengguna mempersiapkan ujian penting seperti SNBT, TOEFL®, dan CPNS. Dikembangkan oleh Paprika Studio, eDucate menawarkan berbagai fitur yang memudahkan proses belajar secara menyenangkan dan efektif.

## 📱 Akses Aplikasi

- [Google Play Store – eDucate](https://play.google.com/store/apps/details?id=com.paprikastudio.educate)

## 🌟 Fitur Utama

- **Bank Soal Lengkap**: Akses ribuan soal latihan untuk SNBT, TOEFL®, dan CPNS.
- **Pembahasan Detil**: Setiap soal disertai dengan pembahasan yang jelas dan mudah dipahami.
- **Analisis Kemajuan**: Pantau perkembangan belajar melalui statistik dan grafik.
- **Mode Latihan Fleksibel**: Sesuaikan waktu dan jumlah soal sesuai kebutuhan.
- **Desain User-Friendly**: Antarmuka yang sederhana dan mudah digunakan.

## 📊 Statistik Pengguna

- **Pengguna Aktif**: Lebih dari 10 juta pengguna di seluruh dunia.
- **Rating Pengguna**: Mendapatkan ulasan positif dari pengguna di berbagai negara.

## 🛠️ Teknologi yang Digunakan

- **Frontend**: React.js, Next.js
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Deployment**: Vercel, Heroku

## 🔧 Instalasi dan Penggunaan

### Prasyarat

- Node.js versi 14 atau lebih baru
- MongoDB Atlas atau database lokal

### Langkah-langkah

1. **Clone Repositori**

   ```bash
   git clone https://github.com/marqynew/eDucate.git
   cd eDucate
   ```

2. **Instalasi Dependensi**

   ```bash
   npm install
   ```

3. **Konfigurasi Variabel Lingkungan**

   Salin file `.env.example` menjadi `.env` dan sesuaikan dengan konfigurasi Anda.

4. **Menjalankan Aplikasi**

   ```bash
   npm run dev
   ```

   Akses aplikasi di `http://localhost:3000`.
